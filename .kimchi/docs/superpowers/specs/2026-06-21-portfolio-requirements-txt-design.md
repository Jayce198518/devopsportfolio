# Portfolio requirements.txt Design

## Overview
A creative `requirements.txt` styled as a professional skills inventory for a Cloud & DevOps Engineer portfolio. The file uses grouped sections, comment headers, and version-like syntax to represent years of experience.

## Sections
All sections derived from the user's actual professional profile:

1. **Cloud & Virtualization** — AWS, Azure, Linux
2. **Container Orchestration** — Docker, Kubernetes, Helm
3. **Infrastructure as Code** — Terraform, Ansible, CloudFormation, Pulumi
4. **CI/CD & Automation** — Jenkins, GitHub Actions, GitLab CI, CircleCI, ArgoCD, Azure DevOps
5. **Monitoring & Observability** — Prometheus, Grafana, ELK Stack, Datadog, New Relic
6. **Agentic AI & Automation** — Claude Code, AI Agents, GitHub Copilot
7. **Scripting & Languages** — Python, Bash, PowerShell, YAML, JSON
8. **Version Control & Collaboration** — Git, GitHub, GitLab, Bitbucket
9. **Networking & Security** — SSL/TLS, IAM, VPN, Firewalls, Load Balancers
10. **Databases & Storage** — PostgreSQL, MySQL, MongoDB, S3, EFS, EBS

## Formatting
- Comment-rich grouped format
- `#` headers for each section
- Short description per tool
- `==` for years of experience (approximate)
- Categories like `Cloud & Virtualization`, etc.
- No emojis

## Output
Single file: `requirements.txt` (or `requirements-devops.txt` if user prefers)
